Ridha Chahed

Machine Learning Engineer · Generative AI & LLMs

I am a Machine Learning engineer at Oracle Zurich in the MySQL HeatWave team, where I develop the MySQL HeatWave cloud service — a fully managed database cloud service on OCI and AWS.

In spring 2021 I interned at NEC Labs Princeton under Eric Cosatto, building deep learning models for cell detection on histology images.

I hold an MS in Data Science (AI focus) from EPFL, where I was a research assistant for Dr Mary Anne Hartley and a teaching assistant for Prof. Martin Jaggi (CS-433). I also hold a BS in Communication Systems from EPFL.

Work

I design and build new machine learning capabilities for HeatWave AutoML — Generative AI, Retrieval-Augmented Generation, and recommendation systems running natively inside the database. I currently focus on deploying Large Language Models and Generative AI in the HeatWave cloud service.
